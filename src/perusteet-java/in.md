# Ohjelmoinnin perusteet Javalla

Tässä osassa kertaamme ohjelmoinnin peruskäsitteitä Java-ohjelmointikielellä.
Käymme samalla läpi hieman Javan erityisiä piirteitä, kuten JVM:ää (Java Virtual Machine) eli Javan virtuaalikonetta.

> 📖 Osaamistavoitteet 
> - Javaohjelman syntaksi, rakenne ja kääntäminen
> - vakiot, muuttujat ja tietotyypit
> - Tulostaminen ja syötteen lukeminen
> - aliohjelmat, metodit
>   - viitearvot
> - luokat ja oliot, 
>   - attribuutit
>   - näkyvyys
>   - kapselointi
